二、青鹰SE Pro

在 SE 的骨架上做增压改进：推力 +12%、比冲 +7%，代价是重量与造价同步上浮。

2.1产品定位

家族第二代。在 SE 的骨架上做增压改进：燃烧室压力与泵功率上抬，换来 112 kN 推力与 311 s 真空比冲；代价是重量、尺寸与造价同步上浮（对比 SE：推力 +12%、比冲 +7%、干重 +8.6%、造价 +56%）。

它不是"更大一号"，而是同一推力级内的效率优化：喷管改成两件式、涡轮泵改成两段式，让同一副骨架承担更高的室压。

2.2核心功能

两件式喷管本体在 y=-1.72 截断，加装独立延伸裙：套筒 + 深色联动环，接缝清晰可见；卸裙即得短喷管（海平面）构型。
两段式涡轮泵 ×2下部细进气管 + 内弯肘管（沿用 SE 手法），上部粗泵体带台阶，暗示更高泵功率。
家族双色顶盘Metal×0.9 / Color_White×0.45 分色，分缝落在 y=0；法兰与 SE 完全一致。
更强的控制力摆角 ±7°（SE 为 ±5°），配合 3.00 的推重比，适合做末级姿控与着陆段。

2.3适用场景

  • 小型运载器芯级 / 单级入轨方案的主动力——112 kN 配 1 m 级贮箱，推重比起飞段约 1.2–1.4。
  • 上面级与轨道机动级——311 s 比冲在同尺寸里偏高，单位推进剂速度增量更划算。
  • 着陆级 / 月面下降级——±7° 摆角便于重心偏移补偿，短喷管（卸裙）构型更贴地。
  • 与 SE 混编——SE 做助推、Pro 做芯级，两者法兰与对接口一致，级间不需要转接件。

不擅长：需要 150 kN 级单机推力的中型构型（此时应选海东青），以及追求最低造价的廉价一次性方案（选 SE）。

三、海东青（HDQ）

青鹰设计语言的直系延续，但构造独立：三级泵、环形集合器、三段喷管，填补 112→150 kN 的空档。

3.1产品定位

青鹰设计语言的直系延续，但作为独立系列的首款：三级泵 + 环形集合器 + 三段喷管。定位在 SE Pro 之上，填补 112→150 kN 的空档，为后续更大推力型号留出接口与命名空间（HDQ-2/HDQ-3）。

与 Pro 的关系是"线性放大 + 局部升级"：推力 +34%、干重 +32%、造价 +36%，单位推力成本几乎不变（0.625 → 0.633 kN/造价），但比冲 +2.3%、摆角 +14% 属于净增益。

3.2核心功能

三级台阶泵体Φ0.370 / 0.442 / 0.408 三级外露台阶，暗示更高泵功率；台阶以圆角过渡，不再刀切。
环形集合器（橙色识别环）两侧内弯肘管不再直插颈部，而是先汇入颈下一圈橙色集合环，再进入泵——家族识别色的构造化。
三段式钟形喷管主段（中灰）+ 深色套筒联动环（出口上方 0.85 m 接缝）+ 浅色延伸裙 + 卷边厚唇口。
桁架加强边梁顶盘下沿一圈深色实心环（半宽 1.033 略大于盘面），承担中型机的承载叙事。
无外露接缝肘管两端均插入实体（顶端深入顶盘、末端径向插入集合环内部），仰视与转动都不露管口。
精确定位色带色带按层高对齐（喉部识别环、集合环为橙色），涂装分界与结构分界严格重合。

3.3适用场景

  • 中型运载器芯级——150 kN 单机，双机并联即 300 kN 级起飞推力。
  • 重型助推并联——推重比 3.06、干重 5 t，作为捆绑助推时结构负担可控。
  • 载人 / 货运上升段主动力——较大的裙段出口（Φ1.15）在低空段提供更高的面积比容差。
  • 重心偏移较大的构型——±8° 摆角比 Pro 多 14%，适合不对称载荷或需要更强配平余量的方案。

不擅长：小推力精细着陆（自重 5 t，最低推力偏大）；预算敏感的一次性上面级（Pro 更划算）。

4.5选型建议

  • 要更轻、更便宜、更短 → 青鹰SE Pro。单位推力造价略优，2.59 m 的短机身对小型构型更友好。
  • 要更大推力或更大摆角 → 海东青。它是"把 Pro 线性放大"的产物，边际成本几乎没有恶化。
  • 混合编队：SE 助推 + Pro 芯级用于小型方案；Pro 助推 + 海东青芯级用于中型方案。

五、安装与部署

两个包互相独立，可同时安装；文件名与标签不影响共存。

5.1安装步骤

01
把 青鹰SEPro.pack 与 海东青引擎.pack 复制到
Spaceflight Simulator Game / Mods / Custom_Assets / Parts /
02
启动游戏，进入 建造界面，在发动机分类中找到两款部件（图标为深色底、橙色识别环）。
03
首次使用若没有出现，退出重进一次（Mod 列表在启动时扫描 Parts 目录）。
04
不需要时直接删除对应 .pack 文件即可，不残留资源。

5.2建造与叠配

  • 两者对接法兰均为 Φ1.000 m、对接口 +0.1125，可与 SE / SE Pro / 海东青任意叠配。
  • 引擎底部出口自带附着面，可作为"引擎串联"或级间分离的基准面。
  • 燃料接口为 Liquid Fuel，与游戏自带贮箱直接连通，无需额外管线。

5.3飞行注意事项

  • 万向节随发动机点火启用：Pro ±7°、海东青 ±8°，可在建造界面关闭以省电。
  • 热区随推力放大：海东青的受热区宽度 1.90（Pro 为 1.55，+23%）、长度 9.2（+10%），贴近其它部件布置时请留出间距。
  • 卸裙构型：Pro 的延伸裙段为独立网格，可在 prefab 中停用该节点获得海平面短喷管（不影响其它部件）。
  • 质心：Pro 在 y=-0.72、海东青在 y=-0.85（自法兰向下），堆叠时注意配平。

5.4调参与重新打包

在 Unity 工程中修改 prefab 的 Part.mass、EngineModule.thrust / ISP、MoveModule 摆角曲线后，用菜单重新打包并自动部署：

SE ProSFS → QingYin Pro → Rebuild + Build + Export Pack海东青SFS → HaiDongQing → Repair Junctions + Rebuild Pack

两个脚本都会把成品直接写入游戏 Mods 目录，并覆盖同名 pack。

数值平衡基于设计建议值，尚未经过长时间飞行实测；若后续调整推力/比冲，建议同步复核推重比与造价，保持"单位推力成本不恶化"这一家族约束。
